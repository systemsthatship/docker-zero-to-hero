# Docker Series — System That Ships

Welcome to the hands-on repository for the **System That Ships Docker Learning Series**.

This repository contains practical demonstrations, source code, Dockerfiles, architecture diagrams, learning resources and challenges accompanying the YouTube episodes.

## What You'll Learn

- Docker fundamentals and architecture
- Docker Engine and Docker Desktop
- Containers and images
- Dockerfiles and custom image building
- Docker Hub and image publishing
- Docker volumes and persistent storage
- Docker networking
- Docker Compose
- Container security and best practices

## Prerequisites

- Basic command-line knowledge
- Windows, Linux or macOS
- Docker Desktop or Docker Engine
- Git and GitHub account
- Docker Hub account for image-publishing labs

## How to Use This Repository

1. Choose an episode folder.
2. Read its README.md.
3. Follow the practical lab instructions.
4. Run the commands on your own machine.
5. Complete the episode challenge.
